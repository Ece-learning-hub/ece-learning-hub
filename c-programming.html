1. What is C Programming?

C is a general-purpose programming language used to develop software, operating systems and embedded systems.

Features of C:

  • Simple and powerful language
  • Fast execution
  • Structured programming
  • Portable across different systems
  • Useful for embedded systems

2. Where is C Used?

  • Operating systems
  • Embedded systems
  • Microcontrollers
  • Device drivers
  • System software
ECE Connection: C programming is useful for microcontrollers and embedded systems.

3. Your First C Program

Let's write a simple C program.

#include <stdio.h>

int main()
{
    printf("Hello World!");

    return 0;
}

Explanation

  • #include <stdio.h> - Includes standard input/output functions.
  • int main() - The main function where execution begins.
  • printf() - Displays output on the screen.
  • return 0; - Indicates successful program completion.

Telugu: printf() use chesi screen meedha message display cheyochu.

Expected Output: Hello World!

4. Variables in C

A variable is a named memory location used to store a value. 

int age = 20;
float price = 25.5;
char grade = 'A';

Telugu: Data ni memory lo store cheyadaniki variables use chestham.

5. Data Types in C

Data types tell the compiler what kind of data a variable stores.

  • int - Stores whole numbers.
  • float - Stores decimal numbers.
  • char - Stores a single character.
  • double - Stores decimal numbers with more precision.
int number = 10;
float marks = 85.5;
char letter = 'A';
double value = 123.456789;

6. Operators in C

Operators perform operations on values.

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Remainder
int a = 10;
int b = 5;

printf("%d", a + b);

Output: 15

7. If-Else Statement

If-else is used to make decisions in a program. 

int age = 18;

if (age >= 18)
{
    printf("Eligible");
}
else
{
    printf("Not Eligible");
}

Telugu: Condition true ayithe if block execute avuthundhi. False ayithe else block execute avuthundhi.

8. Loops in C

Loops repeat a block of code.

For Loop

for (int i = 1; i <= 5; i++)
{
    printf("%d", i);
}

Output: 12345

While Loop

int i = 1;

while (i <= 5)
{
    printf("%d", i);
    i++;
}
