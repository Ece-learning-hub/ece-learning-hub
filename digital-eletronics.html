1. What is Digital Electronics?

Digital Electronics is a branch of electronics that works with digital signals. It uses two values: 0 and 1.

Telugu: Digital Electronics lo mainly 0 and 1 ane rendu values use chestham.

2. Binary Number System

The binary number system uses only two digits: 0 and 1.

Example: 0 = OFF, 1 = ON

Telugu: Binary system lo 0 ante OFF, 1 ante ON.

3. Logic Gates

Logic gates are basic building blocks of digital circuits. The three basic gates are AND, OR and NOT.

AND Gate

Output is 1 only when both inputs are 1.

6. What Did We Learn?

  • Digital Electronics uses 0 and 1.

  • OR gate needs at least one input to be 1.
  • NOT gate reverses the input.
