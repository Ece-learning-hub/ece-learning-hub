1. What is Python?

Python is a high-level, general-purpose programming language. It is popular for web development, automation, data science and artificial intelligence.

Features:

  • Easy-to-read syntax
  • Beginner friendly
  • Large collection of libraries
  • Used in AI and Machine Learning

6. If-Else Conditions

Conditions help a program make decisions.

age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

7. Loops

Loops repeat a set of instructions.

For Loop

for i in range(1, 6):
    print(i)

Output: 1 2 3 4 5

While Loop

i = 1

while i <= 5:
    print(i)
    i += 1
